## 2. 为什么 24h 挂机自训练现在不启动（三重否决）

1. **建不起来**：自训练＝小号全自动 bot 自己打，需执行层(输入注入)＋完整局内循环(暂停/弹窗/结算)＋部署站位决策＋NN 价值网络。全没写（交接"模型代码未写、任何训练都未发生"，P2+）。现只有休整期推荐助手，bot 不会自己买/摆/打。
2. **不对症**：样本主要喂未来 NN；档1规则模型瓶颈在感知+规则。
3. **封号风险**：策划案风险表已拍板"自动化违反用户协议、纯视觉+点击≠零风险、**风险主要来自使用强度**、拟人化节奏+合理运行时段"。24h 连轴＝高强度高风险，违背拍板原则。

## 4. UI 改造（推荐默认＝tkinter 务实档，增强项 A lane ui/，backlog 排期）

四诉求可行性：
- **可调大小**：tkinter resizable，零成本。
- **热键隐显**：Win32 全局热键 ctypes RegisterHotKey（录制器 F9 全局停止先例可复用），避开 F9；隐=withdraw/显=deiconify。中等。
- **半透明**：tkinter `-alpha` 整窗（深底 0.88 保文字可读，但文字一起半透）；`-transparentcolor` 色键抠底＝hack 有锯齿；真"背景全透+文字不透明"逐像素需 **PyQt/PySide 新重依赖**（违背零依赖约束，A lane 重写）。
- **局内覆盖⚠️硬冲突**：助手盖游戏画面上→录制器 mss 截屏幕区域会把助手推荐文字一起截进帧→OCR 读到自己写的字→**感知自污染**；且红线"不遮决策倒计时"。
  解法：① 覆盖放**截屏区域外**（副屏/游戏旁条）最稳零污染；② 改 **Windows.Graphics.Capture 按游戏窗口截**（只截游戏 HWND 不含助手独立窗口）可盖游戏不污染，但 WGC 是 P1 待评估项需验证（BitBlt 冻帧教训）；③ 点击穿透 WS_EX_TRANSPARENT＋避倒计时区。
- **务实推荐**：tkinter -alpha 深底半透＋resizable＋ctypes 全局热键＋安全区覆盖。真悬浮 PyQt 另议。**先定覆盖位置/截屏避污染前提，再美化**。
