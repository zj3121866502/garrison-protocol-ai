# 联机（同盟模拟）样本决策（2026-11-17）

用户原话："能否把多人联机模式的数据也作为参考样本？我想打多人模式。多人模式唯一的区别在于
别人把卡抽完了你可能会抽不到那张特定的卡。你可以搜一下这个机制再告诉我答案。"

**结论：联机录像可以作参考样本，打 mode_tag=coop 区分；但"唯一的区别"不成立。**
共享卡池抽干确实存在（用户说对了方向），另有至少 6 条规则差异，其中 3 条直接改变
已录曲线（生命/层数/抽卡）的语义。样本按信号分级使用，见 §4。

## 1. 共享卡池机制核实（用户提到的那条）

- **有限共享池=真**：4 人共用一个有限卡池，同名干员份数有限，被拿光就刷不出。
  证据链：bilibili 实测视频（盟约赛季 2025-11-18，BV1JWy3BkEpt）：单人卡池也有限；
  联机 4 人共享；实测 I/II/III 阶同名卡位 12/14/18；普通干员占 1 卡位、进阶占 3；
  **卖出即时回流**（队友卖惊蛰后当回合立刻刷出）。社区长期抱怨卡牌（taptap/NGA）；
  粉丝模拟器 CHANGELOG（2026-10-11，声称"按官方"）实现共享池。规程赛季保留共享池。
- **补充①：联机公共池份数翻倍**。CHANGELOG：同盟 5 阶 16 张 / 6 阶 10 张，独立 8/5；
  低阶部分例外。**规程赛季精确份数待核**（KB 代理核对中；盟约实测 12/14/18 不可跨季直接搬）。
- **补充②：自选干员有私人库存**。规程新增"确定自选编队"环节（官方帮助页：战前从已配置
  自选编队选至多 4 名干员加入作战）；CHANGELOG：自选干员私人库存联机同样翻倍，
  且不被翻倍公共池稀释（维护者决定 #650）。→ "别人抽干你抽不到"只适用于公共池干员；
  自选 4 人有私人副本。
- **补充③：装备库存全队共享**（同源 CHANGELOG：普通/进阶装备占 1/2 份，
  商店展示不占份数、购买时再检查）。联机卡牌竞争不止干员。

## 2. 用户没提到的差异（官方现行文本，PRTS 帮助页 2026-11-17 修订 + 规程主页）

1. **联防阶段**（帮助页§联防）：非全员完美作战时，至多 2 名完美玩家阵地迎接所有失败玩家
   漏怪的集合；**联防不能叠层**；规程新增：作战结束退场干员联防继承剩余再部署时间；
   双人联防阵地前后拼接，迎敌优先序=场上人数最多＞已激活盟约(存疑)＞层数最高(存疑)＞
   未被击倒人数最多；失败玩家观战、上方信息栏看自己敌人剩余数。
   → **你的漏怪可能被队友杀掉：联机"你扣的血"≠"你阵地漏的怪"。**
2. **每回合扣血上限 10**（帮助页§回合结束："根据未击倒敌人的数量，扣除其所属玩家的
   目标生命值（每回合最多扣除10点）"）。与规则书 f26 互证。
   → 顺带解释局1 R12 的 -10 致死预览：那是上限值，不是恰好漏 10 个。
3. **领袖轮**（帮助页§领袖作战）：全员剩余目标生命**合并**；**领袖轮战斗内不能叠层**；
   计时结束战斗继续、每超时 1 秒 -1 生命；敌人进目标点把生命扣到 0 则无视倒计时直接失败；
   两两一组左右半场，右侧玩家方向相关盟约效果/部署顺序**左右镜像**。
   → 联机生命曲线 R14 合并、层数曲线领袖轮停涨，与单人语义不同。
4. **决策限时**（帮助页§休整期："计时结束或者所有玩家均完成准备后"进入作战；
   规程主页：联机决策时间有限制、单人休整无限）。机变 6 选 1 轮流获取。
   **具体秒数现行帮助页未列**（盟约旧版 PRTS 有 15 秒；前轮取证的 16s/首 30s/70s
   来自版本差异片段，规程值待核）。→ 联机点击节奏带倒计时压力，timing 特征须分模式。
5. **难度体系不同**（规程主页）：联机=标准/险境/绝境/终极，单人=规程等级 1-20；
   交叉开放映射：险境↔单人至等级3、绝境↔7、终极↔13。敌人强度两模式不同
   （盟约赛季社区实测单人 70%/联机 80%；规程单人官方表=模拟强度 100%-150% 按等级，
   基线不同，跨季数值不可直接搬；联机各档强度值待核）。
   → **战斗校准（档2 漏怪预测）必须按 mode+难度分桶，不能混训。**
6. **退出/观战/惩罚**（帮助页§中止模拟）：联机可随时退出不影响他人；阵亡可观战；
   未阵亡主动退出者（除最后一名）无认证/奖杯，首个退出者多次退出递增禁赛。
   → 联机样本可能出现队友中途离开；胜负是队伍级标签。
7. **资金每回合清零**（帮助页§休整期："本回合的剩余资金将清零，未被冻结的干员/装备
   会随之清空"）。两模式通用，但独立佐证用户"没有一个回合有留钱"的纠正：
   资金根本不跨回合留存，旧"资金留存"解读从根上就错（a/b 是敌人计数之外又一重原因）。

## 3. 红线范围澄清（不静默变更，明示记录）

- 旧红线"不碰联机"的本意=**bot 不在联机局自动操作**（会影响其他玩家）。
- 2026-11-17 用户明确想手动打联机 → 澄清为：
  - 用户手动打联机 + 被动录制（用户自启、零注入）= **允许**，样本打 mode_tag=coop。
  - bot 自动化（含小号）**永不进入联机**。
  - 联机中 bot 推荐=私人提示，用户自己决策，不得遮挡决策倒计时。
- 录制流程不变（仍用户双击 bat/GUI）。**mode_tag 已在录制源实现（2026-11-17）**：
  GUI 新增"对局模式"下拉（单机（独立模拟）/联机（同盟模拟），默认单机），
  写入 meta.json mode_tag=solo|coop；控制台版 --mode coop；bat 不动。
  录制中状态栏显示单机/联机供核对。旧样本无 mode_tag 默认按 solo 处理。
  自动检测（队友头像栏/联防横幅/倒计时）降为可选交叉核对，等有联机帧后再做。

## 4. 样本信号分级（联机数据怎么用）

| 信号 | 单人 | 联机 | 用法 |
|------|------|------|------|
| 干员属性/晋升/装备/手牌机制 | ✓ | ✓ 同规则 | 直接通用 |
| 盟约公式、商店操作语义(click→action)、UI几何 | ✓ | ✓ 主体同 | 直接通用（HUD 主体一致） |
| 经济（回合预算/升级费每回合-1/刷新1资金） | ✓ | ✓ 同规则 | 直接通用 |
| 生命/漏怪标签 | 干净 | 联防截胡+领袖轮合并 | **档2 漏怪校准只用单人**；联机另立标签 |
| 层数曲线 | 战斗可叠 | 联防/领袖轮停涨 | plateau 须先排除规则性停涨再判"操作空洞" |
| 抽卡概率/饥饿监控 | 池=自己买卖 | 池=4人买卖+即时回流 | 归因改变：刷不到可能是队友持有；可选 P1 队友面板 OCR（官方允许点头像看在场干员/盟约/装备）部分重建池状态，成本高 |
| 点击 timing | 休整无限 | 倒计时压力 | 分模式特征 |
| 敌人计数 a/b | 分母=回合敌总数 | 联防时自己敌人在队友阵地打 | 分子口径待证项在联机更复杂 |
| 结局标签 | 个人胜负 | 队伍胜负+个人奖杯维度 | 官方规程页：奖杯含补救能力(联防拦截)/领袖挑战等 → 联机个人表现标签反而更富 |

## 5. 顺手互证项（官方帮助页 ↔ 规则书/已录数据，KB 落地后并入核对）

- 扣血≤10/回合 ↔ 规则书 f26 ✓（解释局1 R12 -10）。
- 资金回合末清零 ↔ 用户"没回合留钱"纠正 ✓。
- 晋升：3 同名初始→销毁 2 发 1 精锐+立即临时刷新 3 名高 1 阶(≤6)干员、费用 0、
  买 1 个退出临时态（帮助页§干员的获得与精锐化）。
- 手牌区规程=10 干员区(含召唤物)+5 装备区；溢出清空规则（帮助页§手牌区）。
- 装备：每干员≤2 件、2 同初始自动合并进阶、佩戴不可手动卸除（帮助页§装备）。
- 技能自动方案优先级：特殊＞分支＞职业＞基础；规程重配方案，
  **纯烬艾雅法拉/澄闪/荒芜拉普兰德限制为仅自己场地敌人触发**（帮助页§技能操作更新记录）
  → 用户核心组合（黑键+纯净艾雅法拉）战斗叠层校准须按规程方案，不能用旧赛季视频。
- 作战时长上限（所有模式同）：R1-2 45s / R3-5 55s / R6 70s / R7-8 85s /
  R9-10 95s / R11-13 115s / 领袖 120s；显示值多约 4-5s（含部署）。
- 部署顺序规程=从上到下＞从左到右（盟约下半改）；首名干员前 3 秒延迟。
