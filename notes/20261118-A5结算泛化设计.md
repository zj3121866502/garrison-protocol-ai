## 4. counter 命名（provisional 值匹配，非定论）

**名字是图标不是文字**（同肖像），硬编码 COUNTER_NAMES=[莱塔尼亚,精准,远见] 只对 224824 成立。
值匹配启发式：取 curves **最后 rest 相位**完整永久层表（末行常是 combat 相位只显当前战斗盟约，不可用）：
- 224824 rest={莱塔尼亚258,精准166,远见67} → settlement 262/168/72 = Δ4/Δ2/Δ5 干净命中。
- 223918 rest={奇迹189,投资人16,灵巧184,炎50,远见80}（5 个）→ settlement 只显 3 个 195/64/16：195→奇迹Δ6、16→投资人Δ0、64→炎Δ14（大）。灵巧184/远见80 未显示→**结算只显子集，选取规则未知**。
- 232000 rest={灵巧15,维多利亚23}（HUD 漏读炎，表不全）→ settlement 23/19/12：23→维多利亚Δ0、19/12 无干净命中。
算法：每槽 v，候选=rest 中 rest_val<=v（结算永久>=rest 永久），取 min Δ 贪心分配（一名一槽）；
置信度 Δ<=8 high / <=20 medium / else low；无候选或 Δ 大→name=null+ambiguous。
**所有名字标 provisional=true**，真命名待 P1 图标模板库。每槽裁图标存 settlement/counter_s{slot}.png 供模板库。
